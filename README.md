# HEY.SSK Reminder App

A local Android reminder application focused on simple, private, reliable reminders without requiring a cloud backend for the core experience.

## Goals

- Fast reminder creation
- Local-first data handling
- Simple notification workflow
- Android-native experience
- Minimal external dependencies

## Platform

- Android
- Kotlin
- Jetpack Compose
- Gradle

## Project principles

HEY.SSK is designed as a focused utility rather than a social or cloud-dependent application. Core reminder behavior should remain useful without requiring a remote service.

## Development

Open the project in Android Studio, allow Gradle synchronization to complete, then run the application on an Android device or emulator.

For a release build, use the Android Studio build tools or the project's Gradle wrapper.

## Repository

This repository contains the Android application source and its build configuration.
